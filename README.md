# AI Real Estate Intelligence Platform

A Machine Learning-powered web application that predicts residential property prices using a Random Forest Regression model. The platform provides an intuitive prediction interface, analytics dashboard, and AI-driven insights to help users understand the key factors influencing property valuations.

## Live Demo

AI Real Estate Intelligence Platform: https://ai-real-estate-intelligence-platform.onrender.com/

## Key Features

* House Price Prediction using Machine Learning
* Interactive Analytics Dashboard
* AI Insights and Feature Importance Analysis
* Modern Responsive User Interface
* Flask-Based Web Application
* Random Forest Regression Model (R² Score: 0.89)

## Technologies Used

* Python
* Flask
* Scikit-Learn
* Pandas
* NumPy
* HTML5
* CSS3

## Machine Learning Model

* Algorithm: Random Forest Regressor
* Dataset: Ames Housing Dataset
* Records Analyzed: 1460+
* Model Performance: R² Score = 0.89

## Project Modules

### Price Prediction

Predicts house prices based on property characteristics such as living area, overall quality, garage capacity, lot size, and construction year.

### Analytics Dashboard

Provides project statistics, model information, and housing market insights.

### AI Insights

Highlights the most influential features affecting house prices and explains how the model makes predictions.

## Live Deployment

The application is deployed and accessible online for demonstration and evaluation purposes.
